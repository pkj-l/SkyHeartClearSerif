# 空心晴明體 / 空心晴宋体 / Sky Heart Clear Serif

基於[《霞鶩銘心宋》](https://github.com/lxgw/LxgwHeartSerif)[《霞鶩新致宋＋》](https://github.com/lxgw/LxgwNeoZhiSong)[《致一宋體》](https://github.com/RiyipuSipino/ZhiyiSerif)及其原始字體的商用免費中文明體。

將《霞鶩新致宋＋》和《致一宋體》字面橫向壓縮 85%，並增加圓角，更加圓潤、輕盈。

本字體包含繁簡兩版，繁體版「空心晴明體（Sky Heart Clear Serif TC）」優先採取《致一宋體》字形，簡體版「空心晴宋体（Sky Heart Clear Serif SC）」優先採取《霞鶩新致宋＋》字形。

> [!NOTE]
> 本字體**不會**與上游字體同步更新。
